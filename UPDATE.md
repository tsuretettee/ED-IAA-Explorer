# How to add a new agreement

## 1. Get the agreement

Go to https://www.ed.gov/about/initiatives/returning-education-states

Find the new partnership (Read the Interagency Agreement).

## 2. Open Section 3

Section 3 is called PERFORMANCE. It has two lists.

* 3.A is what the partner agency does
* 3.B is what ED does

Everything you need is in these two lists.

If the PDF is a scan and you cannot select the text, run it through OCR first (200 dpi or better).

## 3. Sort the numbered items into six groups

Read each numbered item and decide which group it belongs to.

* Statutory authority
* Policy clearance
* Grant administration
* Payments
* Enforcement
* Outreach

Skip anything about IT, cybersecurity, HR, or office supplies. Those are not program duties.

## 4. Fill in the CHART sheet

Add one new row. Use the partnership name from the ED website.

For each of the six groups, write:

* ED if only 3.B has an item
* the agency name if only 3.A has an item
* ED + agency name if both lists have an item
* NOT ADDRESSED if neither list has an item

Two rules:

* If both lists have an item, always write ED + agency. Do not pick one.
* If neither list has an item, always write NOT ADDRESSED.

## 5. Fill in the JUSTIFICATION sheet

Add the same row in the same position.

For each group, copy the wording straight out of the agreement.

* One quote if the chart says ED or an agency name
* Two quotes if the chart says ED + agency, one from each list
* Just the words NOT ADDRESSED if the chart says NOT ADDRESSED

Then paste the PDF link at the bottom of the cell.

## 6. Check it

Copy each quote and search for it in the PDF. If it does not find it, you did not copy it exactly. Go back and fix it.

Check that both sheets have the row in the same place.

Check the link opens.

## One more thing

Some agreements have an addendum stuck on the end of the same PDF. Read it.

If it only changes money, ignore it.

If it changes who does what, refer to that version.
